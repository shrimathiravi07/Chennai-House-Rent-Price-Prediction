About This Project

This web application provides a predictive analysis tool for estimating rental prices in Chennai based on key property attributes like area type, availability, location, size, and amenities. Designed with a user-friendly interface, it leverages machine learning to generate accurate rent estimates and offers a visual insight into prominent city areas. The platform aims to assist tenants and real estate analysts in making informed decisions.
